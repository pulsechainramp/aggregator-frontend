# Supported Assets

> ### Key Points
> - Start with ETH or major stablecoins on Ethereum and arrive with PLS, PLSX, HEX, or bridged stables.
> - Token availability can change with liquidity, so always confirm the contract shown in-app.
> - Add custom tokens to your wallet so balances appear immediately.

**What you'll need**
- Wallet on Ethereum and PulseChain / Token contract list / Explorer links

**Steps**
1. Choose an Ethereum token (ETH, USDC, USDT, or DAI) that you can buy easily.
2. In Bridge, select the matching destination asset (ETH, USDC, USDT, or DAI).
3. After arrival, use Swap to move into other PulseChain assets if needed.
4. Add tokens to your wallet using "Add token" or by pasting the contract address.

**Asset map**

| Origin (Ethereum) | Destination (PulseChain) | Notes |
| --- | --- | --- |
| ETH | WPLS / PLS | Convert to PLS after bridging to pay gas. |
| USDC / USDT / DAI | eUSDC / eUSDT / eDAI | Stablecoins keep the .e suffix on PulseChain. |

**Common mistakes**
- Copying token addresses from unverified sources instead of the in-app selector.
- Expecting a token to appear automatically without adding it to the wallet.
- Forgetting that some assets require wrapping or unwrapping (PLS <-> WPLS).

**Troubleshooting**
- Token missing? Add it manually via contract address or use the Wallet tab to inject it.
- Wrong asset received? Review the Bridge receipt and contact support with transaction hashes.
- Need access to another token? Bridge a stablecoin and swap once you arrive.
