# Wallet Setup

> ### Key Points
> - Pick a trusted wallet: Rabby (desktop), MetaMask (desktop/mobile), or Coinbase Wallet (mobile).
> - Write your recovery phrase on paper and store it offline.
> - Add PulseChain so balances show up as soon as funds arrive.

**What you'll need**
- Computer or phone / Ten minutes / Safe place to store your phrase

**Steps**
1. Install the wallet from the official site or app store.
2. Create a new wallet and back up the recovery phrase immediately.
3. Set a strong password or biometric lock for daily use.
4. Connect your wallet inside PulseChainRamp.
5. Click "Add PulseChain" (or enter the network manually) and approve in your wallet.
6. Copy your address or scan the QR on the Wallet page before buying.

**Common mistakes**
- Saving the recovery phrase only as a screenshot.
- Using a custodial exchange wallet that cannot confirm bridge claims.
- Forgetting to switch back to Ethereum before starting the bridge.

**Troubleshooting**
- Wallet not connecting? Refresh the page and reconnect after unlocking the wallet.
- Missing network? Trigger "Add PulseChain" again and approve the prompt.
- Wrong address copied? Compare the first and last four characters before sending funds.
